<h1 align="center">Tableau Template</h1>

**Tableau 정규과제 템플릿**입니다.  
이 템플릿은 다트비 Tableau 트랙에서 매주 진행하는 강의 학습과 실습 과제를 정리하고 제출하기 위한 기본 구조를 제공합니다.

---

## 🎯 학습 목표

- **Tableau 기본 사용법**을 익히고 데이터를 직접 연결합니다.
- 다양한 차트를 만들며 **시각화 목적에 맞는 표현 방식**을 연습합니다.
- 계산된 필드, LOD, 매개변수, 대시보드 동작을 활용해 **인터랙티브한 분석 화면**을 구성합니다.
- 데이터를 기반으로 **핵심 인사이트를 설명하는 능력**을 기릅니다.

---

## 🗺️ 7주 학습 로드맵

| 주차 | 학습 범위 | 학습 주제 |
| --- | --- | --- |
| 1주차 | 1~8강 | 데이터 연결, 관계/조인/유니온, 라이브/추출 |
| 2주차 | 9~17강 | 데이터 형식, 차원/측정값, 기본 시각화 |
| 3주차 | 18~24강, 28~29강 | 다양한 차트, 필터, 그룹 |
| 4주차 | 30~38강 | 계층, 집합, 계산된 필드, 테이블 계산 |
| 5주차 | 39~47강 | LOD, 매개변수, 서식 |
| 6주차 | 48~57강 | 대시보드, 동작, 최종 프로젝트 기획 |
| 7주차 | 58~66강 중 선택 | 최종 프로젝트 완성, 선택 기능 고도화 |

> 7주차 강의는 전부 필수가 아닙니다. 최종 대시보드에 필요한 기능만 선택적으로 참고하면 됩니다.

---

## ✅ 제출 방법

1. `assignment` 폴더의 주차별 마크다운 파일을 개인 과제 레포지토리에 복사합니다.
2. 각 주차 파일에서 `<!-- 여기까진 그대로 둬 주세요-->` 아래의 작성 영역을 채웁니다.
3. Tableau 실습 화면을 캡처하여 개인 레포 내 이미지 폴더에 업로드하고, 마크다운에 첨부합니다.
4. 과제가 완료되면 **개인 레포 링크**를 과제 제출 시트에 업로드합니다.

---

## 📌 과제 작성 원칙

- 강의 내용을 길게 받아쓰기보다 **핵심 개념과 실습 산출물** 중심으로 정리합니다.
- 1~3주차는 핵심 개념을 표 형식으로 정리합니다.
- 4주차 이후는 계산/LOD/대시보드 개념을 카드 형식으로 정리합니다.
- 매주 **실습 결과 이미지**를 반드시 포함합니다.
- 가능하다면 **Tableau Public 링크**도 함께 첨부하면 좋습니다.

---

## 📊 사용 데이터

1~5주차 과제는 기본적으로 `DArt-B_sample_superstore.xls` 파일을 사용합니다.  
6주차부터는 최종 프로젝트 기획을 위해 자유 데이터를 선택할 수 있으며, 데이터 선택이 어렵다면 Superstore 데이터를 계속 사용해도 됩니다.
